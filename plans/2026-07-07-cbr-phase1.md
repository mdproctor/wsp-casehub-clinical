**Focal issue:** #116 — feat: CBR Phase 1 — wire CbrCaseMemoryStore for AE + deviation + amendment precedents
**Issue group:** #116

**Goal:** Wire casehub-neocortex's CbrCaseMemoryStore into clinical to store and retrieve CBR precedents for AE, deviation, and amendment resolution — demonstrating all three CBR case types.

**Architecture:** Three CDI event observers store CBR cases on resolution events. A thin ClinicalCbrService wraps CbrCaseMemoryStore. Three REST endpoints expose precedent lookup. The InMemoryCbrCaseMemoryStore serves Phase 1; Qdrant is a config-only swap.

**Tech Stack:** Java 21, Quarkus 3.32.2, casehub-neocortex-memory-api (CBR types), casehub-neocortex-memory-cbr-inmem (in-memory store)

**Spec:** `specs/2026-07-07-cbr-phase1-design.md` (design-reviewed, 21 issues resolved)

## Global Constraints

- `api/` module: pure Java only — records, enums, constants. No CDI runtime, no JPA.
- `runtime/` module: CDI beans, JPA entities, services, REST resources (application tier, not a library — REST stays in runtime per existing clinical pattern).
- All `@ObservesAsync` observers that persist state must be `@Transactional`.
- Idempotency: all CBR writers use erase-before-store pattern.
- Feature schemas registered at `@Startup` via `ClinicalCbrSchemaInitializer`.
- `vectorWeight = 0.0` on all CbrQuery instances (Phase 1 — no embeddings).
- Response records in `api/` — no MemoryDomain references from api (MemoryDomain stays in runtime).
- TDD: failing test before implementation. `java-dev` skill for all Java code.
- `requesting-code-review` before each commit. `implementation-doc-sync` after.
- Verify latest blocks-ui and pages versions before Task 6.

package io.casehub.clinical.cbr;
@ApplicationScoped
public class ClinicalCbrService {
    @Inject CbrCaseMemoryStore store;
    public String storeIdempotent(CbrCase cbrCase, String caseType, String entityId,
                                   MemoryDomain domain, String tenantId, String caseId) {
        store.eraseEntity(entityId, tenantId);
        return store.store(cbrCase, caseType, entityId, domain, tenantId, caseId);
    }
    public <C extends CbrCase> List<ScoredCbrCase<C>> retrieveSimilar(CbrQuery query, Class<C> caseType) {
        return store.retrieveSimilar(query, caseType);
    }
}

**Implementation:**
```java
package io.casehub.clinical.cbr;
@ApplicationScoped
public class AeResolutionCbrWriter {
    private static final Logger LOG = Logger.getLogger(AeResolutionCbrWriter.class);
    @Inject ClinicalCbrService cbrService;

    @Transactional
    public void onAeEscalationCompleted(@ObservesAsync AeEscalationCompletedEvent event) {
        try {
            AdverseEvent ae = AdverseEvent.findById(event.aeId());
            if (ae == null) { LOG.warnf("AE not found: %s", event.aeId()); return; }
            TrialSite site = TrialSite.findById(event.siteId());
            ClinicalTrial trial = site != null ? ClinicalTrial.findById(site.trialId) : null;
            String trialPhase = trial != null ? trial.phase.name() : "UNKNOWN";

            Map<String, Object> features = Map.of(
                "grade", event.grade().ordinal() + 1,
                "eventType", ae.eventType != null ? ae.eventType : "UNKNOWN",
                "trialPhase", trialPhase,
                "unexpected", event.unexpected(),
                "suspected", ae.suspected,
                "safetyReviewOutcome", event.safetyReviewOutcome() != null ? event.safetyReviewOutcome() : "UNKNOWN",
                "dsmbEscalated", event.dsmbEscalated(),
                "indReportFiled", ae.regulatorySubmissionStatus != RegulatorySubmissionStatus.NONE,
                "susarOversight", ae.susarOversightStatus != SusarOversightStatus.NONE);

            String problem = "Grade %d %s in %s trial, unexpected=%s, suspected=%s".formatted(
                event.grade().ordinal() + 1, ae.eventType, trialPhase, event.unexpected(), ae.suspected);
            String solution = "Safety review: %s. DSMB escalated: %s. IND report: %s. SUSAR oversight: %s.".formatted(
                event.safetyReviewOutcome(), event.dsmbEscalated(),
                ae.regulatorySubmissionStatus != RegulatorySubmissionStatus.NONE,
                ae.susarOversightStatus != SusarOversightStatus.NONE);

            var cbrCase = new FeatureVectorCbrCase(problem, solution, "COMPLETED", 1.0, features);
            cbrService.storeIdempotent(cbrCase, "clinical-ae", event.aeId().toString(),
                ClinicalCbrDomains.AE, ae.tenantId,
                ae.engineCaseId != null ? ae.engineCaseId.toString() : null);
        } catch (Exception e) {
            LOG.errorf(e, "CBR store failed for AE %s", event.aeId());
        }
    }
}
```

**Data access:** `TrialSite.findById(siteId)` → `ClinicalTrial.findById(site.trialId)` → `trial.phase` for trialPhase (two-hop traversal).

**Interfaces:**
- Consumes: `ProtocolDeviationResolvedEvent` (fields: deviationId, siteId, severity, escalationRequirement, terminalStatus, deviationType, piId, tenantId), `IrbApprovalResolvedEvent` (fields: approvalId, deviationId, siteId, decision, decidedAt, tenantId), `ClinicalCbrService.storeIdempotent()`, `ClinicalCbrDomains.DEVIATION`
- Produces: Stored `PlanCbrCase` with caseType `"clinical-deviation"`

**Implementation — two event observers:**

Observer 1: `@ObservesAsync ProtocolDeviationResolvedEvent` — stores on PI terminal status. For CRITICAL deviations, irbDecision will be null/PENDING at this point.

Observer 2: `@ObservesAsync IrbApprovalResolvedEvent` — re-stores when IRB decides (days later). Erase-before-store overwrites the incomplete case with the full one including actual irbDecision.

Both observers share a private `buildAndStore(UUID deviationId, String tenantId)` method that loads current entity state and builds the PlanCbrCase.

**Plan trace construction:** Load `ProtocolDeviation.engineCaseId`. If non-null, use `CaseInstanceRepository.findByUuid(engineCaseId, tenantId)` to get the case instance. Iterate `planItems` to map completed bindings to `PlanTrace` records. If engineCaseId is null (deviation expired before case started), empty trace list.

Note: `CaseInstanceRepository` is `@Inject`-able. Use `findByUuid(UUID, String)` with tenantId. The case context and plan items are on the `CaseInstance`.

package io.casehub.clinical.cbr;
@ApplicationScoped
public class AmendmentResolutionCbrWriter {
    @Inject ClinicalCbrService cbrService;
    @Transactional
    public void onAmendmentResolved(@ObservesAsync ProtocolAmendmentResolvedEvent event) {
        try {
            ProtocolAmendment amendment = ProtocolAmendment.findById(event.amendmentId());
            if (amendment == null) return;

                event.recommendation() != null ? event.recommendation().name() : "UNKNOWN",
                event.terminalStatus().name(), 1.0);
            cbrService.storeIdempotent(cbrCase, "clinical-amendment", event.amendmentId().toString(),
                ClinicalCbrDomains.AMENDMENT, amendment.tenantId,
                amendment.engineCaseId != null ? amendment.engineCaseId.toString() : null);
        } catch (Exception e) { /* log */ }
    }
}

**AE precedent endpoint (on TrialDashboardResource):**
```java
@GET @Path("/adverse-events/{aeId}/precedents")
public Response aePrecedents(@PathParam("trialId") UUID trialId, @PathParam("aeId") UUID aeId) {
    AdverseEvent ae = AdverseEvent.findByIdForTenant(aeId, principal);
    if (ae == null) return Response.status(404).build();
    TrialSite site = TrialSite.findById(ae.enrollmentId != null ?
        PatientEnrollment.findById(ae.enrollmentId).siteId : null); // resolve site
    ClinicalTrial trial = site != null ? ClinicalTrial.findById(site.trialId) : null;

    Map<String, Object> features = Map.of(
        "grade", ae.grade.ordinal() + 1,
        "eventType", ae.eventType != null ? ae.eventType : "UNKNOWN",
        "trialPhase", trial != null ? trial.phase.name() : "UNKNOWN",
        "unexpected", ae.unexpected,
        "suspected", ae.suspected);

    CbrQuery query = CbrQuery.of(principal.tenancyId(), ClinicalCbrDomains.AE,
            "clinical-ae", features, 10)
        .withMinSimilarity(0.3)
        .withVectorWeight(0.0)
        .withWeight("safetyReviewOutcome", 0.0)
        .withWeight("dsmbEscalated", 0.0)
        .withWeight("indReportFiled", 0.0)
        .withWeight("susarOversight", 0.0);

    List<AePrecedentResponse> results = cbrService.retrieveSimilar(query, FeatureVectorCbrCase.class)
        .stream().map(scored -> mapToAeResponse(scored)).toList();
    return Response.ok(results).build();
}
```

Pattern is similar for deviation (query deviationType, severity, escalationRequirement; weight piDecision/irbDecision at 0.0; retrieve as PlanCbrCase.class; map PlanTrace to PlanStepResponse) and amendment (query with empty features since TextualCbrCase; retrieve as TextualCbrCase.class; all returned with score 1.0 in Phase 1).
